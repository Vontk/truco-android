Primera versión de Truco: contador nativo, mínimo y offline.

- Material 3, Dynamic Color y tema automático.
- Nosotros / Ellos, palitos tradicionales y marcador de 0 a 30.
- Arriba resta; abajo suma. Reinicio con confirmación.
- Guardado local automático e íconos adaptativos normal y monocromático.
- Sin anuncios, rastreadores ni permiso de Internet.

Para Obtainium, usá la URL del repositorio y el filtro de APK `^truco-[0-9.]+\.apk$` (excluye el debug). Las actualizaciones release conservan la misma firma y el marcador.

El APK terminado en `-debug.apk` es para pruebas y usa otro identificador de aplicación.
